How it works 工作原理

A Mac takes a feed from the sound desk. Voice activity detection splits the preacher into sentences, Whisper transcribes each one, a local language model translates it, and a local voice speaks the result. That audio is re-broadcast over the wifi as an ordinary MP3 stream that any phone browser can play, and the transcripts go out alongside it as live subtitles.

Why it's built this way 设计取舍

No app, no accounts

Listeners scan a QR code and press play. It is a web page and an <audio> tag, so it works on whatever phone a visitor walks in with.

Audio never leaves

Speech recognition, translation and the synthesised voice all run on the Mac. No API keys, no per-minute billing, and no recording of your congregation on someone else's server.

Subtitles as well as voice

The same pipeline produces text, so the page shows live subtitles. Useful for deaf members, and for anyone who reads a language faster than they hear it.

A glossary you control

One plain-text file pins your ministry names, your elders' names, and the Bible translation you quote. It is the cheapest quality improvement available.

Setting it up 安装

You need an Apple Silicon Mac with 16 GB of memory, and a USB audio interface taking a feed from the sound desk. Budget about fifteen minutes and 8 GB of model downloads.

git clone https://github.com/nullbotnone/inplace-translation
cd inplace-translation
python3 -m venv .venv && source .venv/bin/activate
pip install speech-to-speech segno && brew install ffmpeg

./start.sh          # prints the QR code to put on your bulletin

There is a launchd agent in the repo so it comes up on its own and a volunteer never has to open a terminal on Sunday morning.

What it is not 限制

This matters more than the feature list. Be straight with your congregation about it.

  • It runs three to eight seconds behind the preacher. Nothing is translated until a sentence ends, and then recognition, translation, speech synthesis and the phone's own buffer all add up. Fine for preaching. Useless for question and answer.
  • It will mistranslate. A model small enough to run on a laptop gets theology wrong in interesting ways. Treat it as help for a visitor who would otherwise understand nothing, not as the sermon of record.
  • A preacher who never pauses will drift. Synthesised speech takes about as long as the original, so there is no slack to catch up. The stream resyncs to live rather than falling further behind.
  • It does not replace a human interpreter. If you have one, keep them.

Under the hood 技术细节

Pipelinehuggingface/speech-to-speech, with the assistant prompt replaced by a translator prompt
Speech recognitionWhisper via MLX
TranslationQwen3 4B or 8B, quantised, running locally
VoiceQwen3-TTS, or Kokoro when you need more speed
Broadcastffmpeg to MP3, fanned out by Python's standard-library HTTP server
SubtitlesServer-sent events on the same connection budget
LicenceApache 2.0, same as the pipeline it builds on
